# StarAchu0418

A personal wrapper around the public Plume web client, with an added optional proactive-message module.

- Upstream UI/API behavior is kept intact.
- No API keys, persona text, memories, or chat data are committed to this repository.
- Personal configuration remains in the browser storage used by the app.
- Proactive messages only run while the web app is able to execute JavaScript; iOS may suspend background tabs/PWAs.

Upstream Plume snapshot pinned at commit `a75300114cf82bc1de5912d3402ae00126f25e5a`.
